# 2fa.hot · 界面规范

版本 1.5 · 2026-09-09。本文描述当前实现；功能范围见 [PRODUCT.md](../PRODUCT.md) 和 [功能矩阵](FEATURE-MATRIX.md)。早期方向图保留在 `docs/design/`，不代表当前界面。

## 设计方向

这是取码工具。主要内容区采用用户选定的 [OreUI](https://katorly.dev/OreUI/zh-CN/) 风格：方形按钮、明暗倒角、凹陷输入框和硬边窗口。通过现有 Nuxt UI 主题实现，不引入外部 UI 运行时；游戏资源来源见 docs 下的来源说明。

`2fa.hot` 保留完整域名，`.hot` 表达“热门”。首页借鉴 Minecraft 标题页的构图，以原创 SVG 灰色立体方块字呈现等高 `2FA`：连续明暗的灰色字面、深灰厚度、近黑轮廓、亮色顶边、底部倒角与少量带亮边的凹刻。单像素细笔画的亮黄色 `.hot` 配细描边与右下硬阴影作为倾斜角标，确保浅色与深色背景上清晰。角标桌面宽 5.75rem、手机宽 4.75rem，以 −20° 倾斜，每 1.15 秒在 1–1.06 倍之间轻微缩放一次；悬停暂停，系统减少动态效果时停用。首页字标与大号验证码构成两个视觉重点；其他页面使用紧凑字标。控件使用中性灰底色，绿色用于主要操作、时间线与焦点。

首页标题下不再显示“输入密钥，获取验证码。”提示语；保留输入与结果工作区、保存状态和一个帮助行。桌面工作区使用一个直角外框，输入与结果以边界分隔，结果面板跟随主题。手机按输入、结果顺序堆叠；空输入时收起结果区，首次输入有效密钥后以 240ms 向下展开，之后编辑时保持展开，仅清空后收起。关闭状态不可聚焦，不参与辅助技术的阅读顺序。

## 字体与层级

界面沿用自托管 Inter 与中文系统字体；域名、密钥和验证码使用 JetBrains Mono。数字使用等宽数字，正文不使用装饰字形。两个字体包按 unicode-range 加载，`font-display: optional`，无外部字体请求。

| 角色           | token / 字号                       | 字重与行高             |
| -------------- | ---------------------------------- | ---------------------- |
| 辅助信息       | `--text-caption: .8125rem`         | 400 / 1.65             |
| 标签、文字操作 | `--text-label: .875rem`            | 400–500 / 1.6          |
| 正文、输入     | `--text-body: 1rem`                | 400 / 1.6；说明页 1.85 |
| 说明页小标题   | `--text-section: 1.125rem`         | 600 / 1.5              |
| 页面标题       | `--text-title: 2rem`，手机 1.75rem | 600 / 1.3              |
| 首页域名字标   | SVG 宽 13.5rem，手机 11rem         | 原创像素轮廓           |
| 桌面验证码     | 6 位 4.5rem；8 位 3.5rem           | 500 / 1.3              |

验证码字号按容器缩小：中等宽度 3rem / 2.25rem；最窄屏幕 2.75rem / 2rem。独立取码页桌面 4rem / 3.25rem。字标与验证码属于有意设置的展示字号，不用于普通正文。

说明页文字宽度不超过 44rem；中文标题不额外拉大字间距。验证码保持可选中、不会滚动成中间数字。页面允许浏览器缩放。

## 色彩与表面

基础样式位于 [main.css](../../app/assets/css/main.css)，Ore 风格的表面、边缘与交互令牌集中在 [ore.css](../../app/assets/css/ore.css)。

- 内容区浅色画布与结果区：`#E6E8EB`；输入面板：`#F4F6F9`；主体文字：近黑。
- 内容区深色画布：`#1E1E1F`；面板：`#313233`；主体文字：近白。
- 主要操作采用 Minecraft/Ore 绿色 `#3C8527`，悬停 `#2A641C`，复制成功 `#1D4D13`；深色文字强调色为 `#6CC349`。
- 成功与错误颜色仅表达状态，不能只靠颜色传达结果。
- `.ore-theme` 只覆盖主要内容与其弹窗，直角控件使用 `--ui-radius: 0`；2px 边缘与无模糊的硬阴影表现厚度，按下按钮下移 2px。header/footer 沿用简洁导航，不使用 Ore 边框与阴影；顶栏菜单保留 Nuxt UI 默认圆角。
- 不使用渐变字、发光图标、网格背景或重复的安全承诺。

## 布局

全站顶栏使用独立的石灰色 `2fa.hot` 文字标识，通过细高光和硬阴影表现材质，不复用首页方块造型、不使用黄色角标与动画。顶栏包含取码/历史/说明导航和主题菜单，导航控件保持普通样式。手机收进菜单。独立取码页使用简化导航。页脚只放项目名、隐私与 [项目 GitHub](https://github.com/LZSMIAO/2fa-hot)，不加入个人主页。

首页最大外宽 69rem，桌面内边距 2.5rem。工作区列比例 0.95 : 1.05，结果获得更宽的数字显示空间。700px 以下“单条取码 / 批量取码 / 不会用？”同排等高；工作区上下堆叠，960px 以下收紧留白。输入控件至少 44px 高，常用图标按钮与文字操作保持可点击面积。

历史、二维码和导出界面沿用同一文字层级。空状态只说明下一步，不铺陈产品口号。说明页提供页内锚点。

## 动效

- **按钮音效**：使用 Mojang 官方 `ui.button.click` 原始资源，默认开启，手动关闭后在本机记住偏好；首次真实点击时播放，悬停与自动教学静音。顶栏统一 Lucide 20px 图标与至少 44px 点击区域。音效来源见 [AUDIO-SOURCE.md](../AUDIO-SOURCE.md)。

- **Nuxt UI Tabs**：方形按钮切换绿色选中状态；内容切换 180ms 微幅淡入。保留已输入内容。
- **内容弹窗**：二维码导入、导出和历史弹窗以 20px 水平位移在原位附近进入（180ms），退出 120ms；遮罩同步淡入淡出，不做屏外长距离飞入或中心缩放。这是本站按 Ore 方向调整的参数，不标作官方规范。关闭动画结束后卸载临时窗口，摄像头在开始关闭时立即停止。
- **Nuxt UI Collapsible**：参数区域展开/收起；箭头 200ms 旋转，与内容状态一致。
- **NumberFlow for Vue**：只动画化剩余秒数，变换 180ms、透明度 120ms，固定两位数字。
- **验证码空状态**：六个低对比度像素码位分为两组三位，边缘依次轻亮一次后静止；生成数字时 160ms 原位淡入，空状态与六位数字等高，减少动态效果时停用。
- **倒计时**：十段进度槽展示剩余时间，同时保留秒数与到期提示。
- **复制反馈**：图标与按钮状态 120–180ms 过渡；真实复制成功后才显示深绿色与“已复制”。
- **减少动态效果**：CSS 使用 `prefers-reduced-motion` 关闭过渡，NumberFlow 遵循其默认系统偏好支持。

页面初始内容直接可用；仅标题角标保留用户指定的持续缩放动画。

“不会用？”再次点击可关闭，打开时按钮显示“关闭教学”；同时支持窗口关闭按钮与 Esc，退出后焦点回到入口。教学以固定浮层从右侧滑入示例社交账号窗口（进入 420ms、退出 240ms），中间卡片的位置和尺寸保持不变；先简述 Authenticator 和基于密钥、时间生成验证码的原理。模拟鼠标在该窗口与真实首页之间移动，使用公开密钥取码并填写示例验证窗口。约 14 秒，支持暂停、重看；减少动态效果时手动逐步播放。演示不读取或写入系统剪贴板，不登录真实账号，结束后恢复原输入。原“试用演示”入口已移除。

## 功能边界

标题页背景使用 Minecraft 1.20.1 樱花林全景，180 秒匀速循环旋转，光照与明暗遮罩隔离在背景层。前景卡片保持不透明；深浅主题均不得改变页面根元素的透明度。提供暂停按钮，后台标签页和系统减少动态效果设置下停止动画。素材来源见 `docs/PANORAMA-SOURCE.md`。

保留 `/2fa/:secret` 链接。首页密钥本地计算，路径型链接会经过托管服务。`no-store`、禁止来源传递与禁止索引设置保持原有语义。视觉修改不改变 TOTP、加密或存储协议。
