# 2FA 功能对照与交付范围

核对日期：2026-09-07。来源：[2fa.run 首页](https://2fa.run/)。使用浏览器插件读取功能名称和说明，未复制样式、截图、布局、素材或代码。浏览器中的密钥和历史内容不作为研究数据保存。

证据为界面和说明，不代表已测试参考站每个按钮、后端或存储实现。“页面未见”表示本次检查未发现，不表示对方绝对不支持。

## 参考站功能覆盖

| 参考站功能         | 本站设计                                                   | 规范位置    |
| ------------------ | ---------------------------------------------------------- | ----------- |
| 输入密钥获取验证码 | 单条密钥或 TOTP URI，本地计算                              | DESIGN §8–9 |
| JS / PHP 两种入口  | 统一本地取码，覆盖同一用户任务，不上传密钥计算             | §17         |
| 当前密钥展示       | 默认遮蔽，可主动显示                                       | §8          |
| 当前验证码         | 等宽分组、保留前导零                                       | §7、9       |
| 剩余时间倒计时     | 秒数、进度、临近更新提示                                   | §9          |
| 获取后自动复制     | 显式获取并复制，含成功/失败反馈                            | §17         |
| 二维码生成         | 标准配置码，增加 PNG 下载与 URI 复制                       | §16         |
| 本地密钥历史       | 主动开启后加密保存                                         | §18         |
| 历史备注           | 每条记录的标签与备注，可搜索                               | §18         |
| 清除全部记录       | 独立操作、数量与二次确认                                   | §18         |
| 演示密钥和说明     | 公开演示、持续标记、帮助内容                               | §11、17     |
| 网址携带密钥取码   | 独立 `/2fa/:secret` 获取页，打开即显示验证码，支持直接刷新 | §17、20     |

“全部具备”指覆盖 2FA 任务能力。用户明确要求沿用 `/2fa/密钥` 的快捷访问格式，并提供与首页分开的独立获取页；实现语言与前端设计不沿用对方。用户已确认默认不保存，可主动开启历史，排除非 2FA 工具。

## 边界与视觉资产

不注册网站账户、不云同步，本地口令只用于加密解锁。不包含文本处理、通用图片处理、汇率等工具。不宣传绝对安全或已通过安全审计。
